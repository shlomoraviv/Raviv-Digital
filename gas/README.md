# לייקים וצפיות לאתר — מדריך פריסה (רביב דיגיטל)

האתר (GitHub Pages — סטטי) סופר **לייקים ("אהבתי")** ו**צפיות** לכל פריט:
התוכנות להורדה, כרטיסי המחירון ותיק העבודות.
המספרים נשמרים בגיליון Google Sheets דרך **Google Apps Script** — כך כל הגולשים
רואים את אותם מספרים, ואתם מקבלים פידבק אמיתי על כל פריט.

## איך זה עובד מבחינה טכנית

- **קריאת המספרים** — האתר טוען את הספירות מ-`action=counts` ב-**JSONP**
  (עוקף את מגבלת ה-CORS של Apps Script, אין צורך בשרת משלכם).
- **לייק / צפייה / ביטול לייק** — נשלחים כבקשת GET "ביקון" (`new Image().src`),
  שאינה דורשת CORS כלל.
- **ספירה הוגנת** — לייקים נספרים לפי מבקר ייחודי (אותו אדם נספר פעם אחת),
  וצפיות נספרות כסה"כ: כל כניסה לאתר שבה הפריט הוצג מוסיפה +1,
  עם הגנת רענון (פעם אחת לכל סשן דפדפן לכל פריט).
- **צפייה נרשמת** כשכרטיס נכנס למסך (IntersectionObserver) — פעם אחת בכל סשן
  לכל פריט.
- **הגיליון** — נוצר אוטומטית בדרייב שלכם בשם
  `לייקים וצפיות - רביב דיגיטל`, עם הגיליונות `ליקים`, `צפיות`
  (תאריך, פריט, מזהה מבקר) ו-`התראות` (מעקב אחר הספים שכבר דווחו במייל).

## התראות במייל

הסקריפט שולח מייל אוטומטי:
- **צפיות** — כל **25 צפיות חדשות** באותו פריט (25, 50, 75…).
- **לייקים** — כל **5 לייקים חדשים** באותו פריט (5, 10, 15…).
- **סיכום חודשי** — ב-1 לחודש בשעה 09:00 מייל מעוצב עם טבלת סיכום:
  לייקים וצפיות של החודש וסה"כ לכל פריט, כשהפריט הפעיל ביותר זוכה 🏆.

המיילים נשלחים ל**חשבון שמפעיל את הסקריפט**. אפשר לשנות יעד ותדירות
בבלוק `CONFIG` בראש `LikesViews.gs`:

```js
var CONFIG = {
  ...
  EMAIL_TO: '',            // ריק = לחשבון שמפעיל. אפשר להזין כתובת אחרת.
  VIEW_EMAIL_EVERY: 25,    // מייל כל כמה צפיות חדשות
  LIKE_EMAIL_EVERY: 5      // מייל כל כמה לייקים חדשים — שימו 1 לכל לייק
};
```

## שלבי הפריסה (פעם אחת בלבד)

1. נכנסים ל-[script.google.com](https://script.google.com) → **פרויקט חדש**.
2. מדביקים את כל התוכן של **`LikesViews.gs`** בקובץ `Code.gs`.
3. מריצים ידנית פעם אחת את הפונקציה **`setup()`**:
   בוחרים `setup` בשורת הפונקציות → **Run** → מאשרים את ההרשאות
   (גישה לגיליונות, לדרייב ולשליחת מיילים). זה יוצר את הגיליון.
4. (אופציונלי, מומלץ) מריצים פעם אחת את **`setupMonthlySummaryTrigger()`**
   כדי להגדיר את הטריגר החודשי. (לביטול: `removeMonthlySummaryTrigger()`).
5. פורסים: **Deploy → New deployment → Web app**:
   - **Execute as:** Me (החשבון שלכם)
   - **Who has access:** Anyone
   - לוחצים **Deploy** ומאשרים.
6. מעתיקים את כתובת ה-**Web app URL** (מסתיימת ב-`/exec`).
7. באתר: פותחים **`index.html`**, מוצאים את השורה
   `const LIKES_URL = 'https://script.google.com/macros/s/AKfycbREPLACE_ME/exec';`
   ומחליפים אותה בכתובת שלכם, לדוגמה:
   ```js
   const LIKES_URL = 'https://script.google.com/macros/s/AKfycb...../exec';
   ```
8. דוחפים את השינויים ל-GitHub — והמערכת פעילה.

> **טיפ:** אחרי כל עדכון של הסקריפט (Deploy → Manage deployments → Edit → New version)
> הכתובת נשארת זהה — אין צורך לשנות אותה באתר.

## הוספת מונים לפריט חדש באתר

```html
<!-- כל קונטיינר שרוצים לספור צפיות עליו: -->
<div data-rv-view="my-new-item"> ... </div>

<!-- הצגת המונים: -->
<div class="rv-stats" data-rv-counts>
  <span class="rv-pill">
    <i class="fa-regular fa-eye"></i>
    <span class="rv-num" data-rv-views="my-new-item">–</span>
  </span>
  <button type="button" class="rv-like-btn" data-rv-like="my-new-item">
    <i class="fa-regular fa-heart"></i>
    <span class="rv-num" data-rv-likes="my-new-item">–</span>
  </button>
</div>
```

המזהה (`my-new-item`) הוא טקסט חופשי עד 60 תווים — הוא מופיע גם במיילים
ובגיליון, אז עדיף שם ברור באנגלית.

## ניפוי תקלות

- **המספרים לא מופיעים** — ודאו שהכתובת ב-`LIKES_URL` תקינה ושהפריסה היא
  עם גישה ל-**Anyone** (לא "Anyone with Google account").
- **הודעת שגיאה בתשובת השרת** — פתחו את הכתובת
  `LIKES_URL?action=counts` ישירות בדפדפן וראו מה מוחזר.
- **הגיליון לא נוצר** — הריצו שוב את `setup()` ואשרו הרשאות.
- **לא מגיעים מיילים** — ודאו שאישרתם הרשאות **שליחת מייל** בהרצה הראשונה.
  לבדיקה מהירה הריצו ידנית את `sendMonthlySummary(0)` — יישלח סיכום
  של החודש הנוכחי.
- **אבחון כללי** — הריצו ידנית את `diagnose()` וראו את הפלט ב-View → Logs.
